# Code of Conduct

## The short version

Be direct, be technical, and do not be a jerk.

This project is fine with blunt engineering feedback. It is not fine with harassment, intimidation, dogpiling, bigotry, or making the repo miserable for everyone else.

## Expected behavior

- Critique code, architecture, and ideas clearly.
- Bring evidence when you disagree.
- Assume good intent until someone proves otherwise.
- Help keep docs and examples accurate for humans and LLMs.

## Unacceptable behavior

- personal attacks
- harassment or stalking
- discriminatory language or conduct
- threats, doxxing, or intimidation
- deliberately wasting maintainer time with spam, bad-faith issues, or hostile review behavior

## Enforcement

Maintainers may edit, delete, lock, or reject content that makes the project worse. Repeated bad behavior can mean temporary or permanent bans from the repo.

If you see a problem, report it privately through the same path described in `SECURITY.md` or through GitHub contact channels.
